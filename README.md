# portfolio

Source for saiprakash.design. One static page, no build step.

## Deploy
- **Vercel:** import this repo, framework "Other", no build command, output directory `.`
- **GitHub Pages:** Settings → Pages → deploy from branch, root folder.
- Point `saiprakash.design` at whichever host you pick; the canonical and Open Graph URLs already use it.

## Before going public
- Confirm the bank-work wording is cleared for public sharing (publication freeze on patent candidates).
- Confirm the "open to roles" line in the contact section.
- Add a 1200×630 `og-image.png` and a favicon.
