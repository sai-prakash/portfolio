## Why

Every design system team now has a new user: the coding agent. Some systems are much easier for agents to use correctly than others, and almost nobody measures it.

## What it does

ds-bench-de gives the same set of UI tasks to coding agents working with different public design systems, then grades the output with automated checks: did the agent use the system's components, its tokens, accessible markup? The result is a leaderboard of agent readiness.

## Systems in scope

SAP UI5, Siemens iX and Telekom Scale to start, all public design systems from German companies.

[See the repository on GitHub](https://github.com/sai-prakash/ds-bench-de)
