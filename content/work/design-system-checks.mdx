## The problem

Coding agents write UI fast, but they guess. Hard-coded colours, hand-rolled buttons and missing labels slip into production because nobody can see them at scale. The same problem existed before agents; agents just multiplied it.

## What I built

It started as a linter for a hackathon: point it at an app, on screen or in code, and it shows where the design system is being broken. It works on apps that were never built on the system, which turned out to matter most, because those are the apps teams want to migrate. It won the hackathon, and teams started asking for it after the first demos.

From there it became a way to grade agent output. The same checks score what an agent generates, so a team can tell whether a new prompt, model or doc change actually made the output better.
