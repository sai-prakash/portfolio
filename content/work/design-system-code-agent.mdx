## The problem

General code generators ignore the design system, so the screens they produce get rebuilt by hand. The faster the generator, the more rework it creates.

## The move

An in-browser agent that builds screens only from the design system's real React components, and runs checks before anything is shown. If the system doesn't have a part, the agent can't invent one.

## Where it is

Single-screen and multi-screen generation work. The goal is React, iOS and Android for 5,000+ internal users. Feedback pushed the work toward real production screens, so I'm building a corpus from them to validate against.
